## The Challenge

In technical interviews, having both candidate and interviewer type simultaneously into an online code buffer without overwriting changes is surprisingly difficult.

Simple timestamp-based reconciliation leads to lost keystrokes.

## Architectural Approach

We adopted a hybrid model:
- **WebSocket transport** for minimal latency full-duplex messaging.
- **Operational Transformation / CRDT primitives** to resolve concurrent edits on character ranges.

```javascript
socket.on('code-delta', (delta) => {
  editor.applyDelta(delta);
});
```

## Takeaways

- Always acknowledge change delivery with sequence IDs.
- Buffer changes locally when the socket drops and resynchronize on reconnection.
